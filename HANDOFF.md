# Presenter handoff

## Start and prepare

1. From this folder, run `./start.ps1 -Port 8013` if the local server is not running.
   Use the existing local `.env`; never put credentials into presentation materials.
2. Open http://127.0.0.1:8013. Sign in as `trainer` with `LearnDemo2026!`.
3. Open **Progress → Start fresh live demo**. Confirm the fictional rehearsal banner
   says AI coach and the original expense procedure is selected.
4. Before judging, complete the original-policy journey and review a draft revision.
   Keep it unactivated. Disclose this prepared evidence when presenting.
5. During the pitch, show the earlier coaching decision, activate the reviewed update,
   and demonstrate the one-objective refresher. Follow PITCH.md.

## If something interrupts the demonstration

| Situation | Response |
| --- | --- |
| Model request is slow | The selection status explains the wait. Continue narration; do not repeatedly click. |
| Explicit gateway error | Retry once. If unavailable, use the labeled offline replay or start a separate offline rehearsal. |
| Browser reload | Saved activity, evidence and decisions resume. |
| Wrong rehearsal or completed policy | Return to main workspace, then create a fresh rehearsal from trainer Progress. |
| Need to switch learner/trainer | Sign out and sign in in the same rehearsal. The banner remains. |
| Need original workspace | Use Return to main workspace. Rehearsal data is retained separately. |

Tabs in the same browser share the selected rehearsal. Do not use another tab as
though it were a separate tenant or independent rehearsal.

## What is safe to claim

“Three unchanged objective records carried forward; one required a refresher.”
“The backend required every critical objective and scored the fresh cases.”
“The agent selected an eligible approved activity from saved learner evidence.”

Do not turn those statements into measured time savings, improved retention,
certification, autonomous policy approval, or a production-readiness claim.

walkthrough; REHEARSAL.md for observed results; backup-demo.gif for a silent offline
illustrated replay. A true screen-recorded video remains to be recorded if required
by the organizer.
