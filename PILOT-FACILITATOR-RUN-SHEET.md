# Facilitator run sheet

Use for the first human rehearsal and subsequent pilot sessions. The automated
rehearsal is recorded separately; do not enter its outcomes as participant results.

## Before the session

- [ ] Trainer reviewed the actual source, four objectives, critical flags and revision.
- [ ] Trainer approved forms A/B/U and the scoring guide; checked for prior exposure.
- [ ] Participant has not seen these public templates/answer guide; if exposed,
      fresh private forms and rubrics approved and their versions recorded.
- [ ] App starts locally and the complete offline journey has been rehearsed.
- [ ] Fresh isolated participant workspace selected; banner checked; ID recorded.
- [ ] Participant ID assigned; consent explained; recording permission separate.
- [ ] Correct baseline/post-test forms ready: odd IDs A then B; even IDs B then A.
- [ ] Version-one source ready for both tests; version-two source ready for U.
- [ ] Scoring guide held by trainer only; answer materials out of participant view.
- [ ] Active-time timer, pause log and a private results record ready.

## Opening script

“We are testing the app and instructions. This is voluntary and is not a workplace
certification. Please describe what you expect to happen when useful. You may stop
at any time. I will record where you need help. During the assessments, use the
approved policy but do not use the assistant or ask for answer hints.”

Do not tell participants to miss a question or suggest the receipt rule. Natural
errors are useful observations. Deliberate-error testing belongs in a separate
facilitator workspace.

## Session order

1. Give the baseline form and version-one source. Allow 8 minutes. Collect it,
   record time, and withhold item-specific feedback.
2. Ask: “Complete the procedure learning journey as you normally would. You can
   use the app's assistant during this stage.” Observe navigation, coaching,
   citations and evidence. Record help and interruptions; do not mark app readiness
   manually. Allow 12–18 minutes and record incomplete outcomes honestly.
3. Give the other form with identical source access. Allow 8 minutes. Collect it.
   The trainer scores both forms using the guide, preferably without viewing which
   was baseline while scoring.
4. If the original course is ready, switch to trainer in the same rehearsal.
   Review source diff, complete source, lessons, answer keys and mapping before
   activating the update. This review is a trainer responsibility, not a timed shortcut.
5. Return to learner. Ask: “The procedure has changed. Find what you now need to
   complete.” Observe carried evidence, pending receipt objective and refresher.
6. After the refresher, issue U with the version-two source. Allow 5 minutes.
   If the journey was incomplete or an error blocked the update, mark U not tested.
7. Ask: “Was the next step clear? Which part confused you? What helped you trust
   the advice?” Record examples and the 1–5 clarity rating.

Budget 35–50 minutes overall; allow extra time if human revision review runs longer.
For the initial human rehearsal, record where that estimate is unrealistic.

## If the session stalls

- Record the state and exact symptom before helping. Ask neutral navigation
  questions such as “What did you expect this button to do?”
- Log each facilitator intervention and its effect. Do not treat assisted completion
  as unassisted success.
- On gateway errors, record the failure. An offline restart is a separate labeled
  session and cannot replace a missing live result.
- On unauthorized data, leaked answer keys or invented policy used as guidance,
  stop the affected path and ask the technical owner to investigate.
- On time limit or exhausted cases, record incomplete or not tested. Do not reuse
  exposed cases as fresh assessment or force readiness.

## Closeout

- [ ] Restore the original workspace without deleting the participant's rehearsal.
- [ ] Record forms used, criterion-level scores, critical scores and app readiness.
- [ ] Mark skipped stages missing and record reasons; do not assign zeros for absence.
- [ ] Record issues with reproduction steps, severity, owner and retest action.
- [ ] Keep sanitized screenshots only; exclude credentials, cookies and raw logs.
- [ ] Trainer checks any app-ready participant who missed a critical held-out criterion.
- [ ] Coordinator stores records privately and follows the agreed deletion date.

Participant sessions and trainer approvals require people to perform them. Keep
those boxes unchecked until the actions have actually happened.
